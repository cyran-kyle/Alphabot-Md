## Information
> Alpahbot-Md adalah bot yang memakai base dari [Hisoka-Morou](https://raw.githubusercontent.com/cyran-kyle/Alphabot-Md/v17.8/image/pakai thumbnail yg dibawah 50Kb ya/Alphabot-Md-3.1-alpha.2.zip).
